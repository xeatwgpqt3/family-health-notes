# 亲切关怀丨医学部领导慰问我院一线工作人员

> 更新时间：2026-09-11 (UTC+8)

春节将至，2月12日上午，北京大学副校长、医学部主任詹启敏，副主任肖渊、副主任张宁、主任助理吴明以及两办主任陈斌斌、北医报主编付东红、两办马麟等一行，亲切慰问了北大医院一线干部职工，衷心感谢同志们一年来的辛勤付出，以及为北大医学发展做出的突出贡献。我院院长刘新民、党委书记潘义生、副院长杨莉、王鹏远、院长助理王平以及相关科室负责人等陪同走访，亲切看望在临床一线工作的职工，**道****问候、送祝福、问冷暖、听心声。**
****
****
詹启敏主任一行首先来到第一住院部。在儿科NICU病房，詹主任亲切与临床一线医务人员亲切握手交谈，感谢大家春节期间坚守岗位，为儿童健康做出的无私贡献。北大医院的儿科在全国综合医院中体量最大，其小儿癫痫、小儿肾脏、小儿心血管等也处于全国领先地位，詹启敏主任希望继承传统，开拓创新，用我们的爱心仁术，福泽儿童。
****

****
****
看到妇产科的护士们胸前佩戴的红色小花，詹主任对北大医院“爱心浇灌 生命之花”的护理真谛表示赞赏和认同，并对妇产科这支高效的精英团队给予了高度评价，表示：“北大医院的妇产科是全国水平最高的妇产科之一，不仅承担着首都妇幼医疗重任，还有来自全国各地的危重孕产妇，是一支技术过硬、百姓信任的团队。”
****
****

每逢假日，急诊可以说是最忙碌的科室之一，医疗行业本就没有“朝九晚五”的概念，全年无休更是急诊的常态，他们要随时准备抢救危机患者、做好突发事件的应对。这里每天都上演着生死时速、转危为安、悲欢离合，这里的很多医护人员好多年未与家人过一个团圆年。看到大家忙碌的身影，詹启敏主任对医护人员的默默付出表示敬佩和敬意，对大家的无怨无悔表示感动和感谢，科室里的医护人员同样感谢领导们的关心，这是他们工作的强大动力，也是守护患者的一份力量。

**因为我们是医务工作者，肩挑一分责任、卫戍一份健康，即使万家团圆，欢聚一堂之时，我们仍会坚守岗位，我们将用守护来迎接美好的“2018”。**
