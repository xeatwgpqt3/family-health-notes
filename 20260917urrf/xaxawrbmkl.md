# 顶风冒雪，“医”路前行！

**冬日の大雪**

这两天

滨州开启“雪雪雪”模式

纷纷扬扬的大雪

无声无息的落下

院内外银装素裹

到处都是白茫茫的一片

**扫雪破冰，确保“医”路畅通**

为应对暴雪天气，滨州医学院附属医院高度重视，召开会议，提前部署，制定应急预案。

**/ 扫雪啦 /**

12月14日傍晚时分，院区内开始出现了积雪和结冰的情况，影响患者的安全出行。院领导立即带领行政后勤的职工以雪为令、迎雪而上，积极开展院内外清雪行动。

15日一大早，大家又不畏严寒，纷纷出动。凛冽的寒风中，你一铲，我一锹，破冰除雪，撒盐铺路，一双双勤劳的手，在寒风中挥动着，他们团结协作，奔波忙碌的身影形成了一道靓丽的风景。经过积极奋战，大家将院区出入口、道路上的积雪清除干净，为来院就诊患者及家属提供了一个安全的出行环境。

**顶风冒雪，打通急救通道**

同样风雨无阻的

还有急诊团队

他们顶风冒雪

与时间赛跑

为生命奔忙

大雪来袭，每一次出诊都变得格外艰难，但对于急救人来说没有完不成的任务，更没有克服不了的困难。他们在恶劣天气下拼尽全力，只为圆满地完成了各项急救任务，保障百姓的生命安全。

风中，有了他们的坚守，患者就医更加心安；雪中，有了他们的奋战，寒冬变得分外温暖。

从14日下午到15日中午12点，他们已出诊35次。目前滨州大街小巷结冰湿滑，但他们的出诊任务仍在继续……

**诊疗区域，依旧秩序井然**

尽管大雪纷飞，尽管道路湿滑，但没能阻挡滨医附院人上班的脚步，大家坚守岗位，无缝对接，随叫随到，用心用力用情维护医院正常有序运行。
